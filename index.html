01 / Toolkit

Những mảnh ghép thiết yếu.
Không thêm gánh nặng.

API nhỏ, rõ ràng và có kiểu dữ liệu. Chỉ lấy những gì cần dùng, tích hợp vào stack hiện có.

Aa

String utilities

Tạo slug, đổi kiểu chữ, escape HTML và cắt chuỗi an toàn.

{ }

Object helpers

Pick, omit, deep merge, đọc đường dẫn lồng nhau và clone JSON.

↻

Async control

Retry với exponential backoff, timeout, deduplication và sleep hỗ trợ abort.

↗

URL & HTTP

Quản lý query parameters, parse URL và gửi request JSON có kiểu.

✓

Validation

Kiểm tra email, URL HTTP(S), record, khoảng số và điều kiện đầu vào.

⌘

Developer ready

TypeScript strict, Node test runner, source maps và GitHub Actions CI.

02 / Quick start

Bắt đầu trong vài lệnh.

Clone repository để khám phá mã nguồn, chạy kiểm thử và build cục bộ.

Terminal · Node.js 18+
git clone https://github.com/Velclaw/OCode.js.git
cd OCode.js
npm install
npm test
npm run build
TypeScript · Example
import { slugify } from "./src/string";
import { retry } from "./src/async";

const slug = slugify("Build a better web");

const result = await retry(
  async () => fetch("/api/status"),
  { attempts: 3, delayMs: 200 }
);

Lưu ý: package chưa được phát hành lên npm. Hãy dùng repository và kiểm tra hướng dẫn trong README trước khi import từ package name.
