quick-start.ts
// Dùng các helper theo từng nhu cầu
import { slugify, withQuery, retry } from "ocode-js";

const slug = slugify("Build a better web");
const url = withQuery("/docs", { page: 2 });
console.log({ slug, url });
Bộ công cụ

Tập trung vào những thứ bạn cần

Các hàm nhỏ, dễ kết hợp, có kiểm thử và được viết bằng TypeScript strict.

Aa

String utilities

Tạo slug, đổi kiểu chữ, escape HTML và cắt chuỗi an toàn.

{ }

Object helpers

Pick, omit, merge đệ quy, đọc đường dẫn lồng nhau và clone JSON.

↻

Async control

Retry, timeout, deduplicate lời gọi bất đồng bộ và sleep có hỗ trợ abort.

↗

URL tools

Parse URL, cập nhật query, nối URL và loại bỏ tracking parameters.

✓

Validation

Kiểm tra email, HTTP URL, record, khoảng giá trị và điều kiện đầu vào.

⌁

HTTP & runtime

Fetch JSON có kiểu, browser storage an toàn, env helpers và logger.

Tích hợp vào dự án của bạn

Gói hiện đang ở giai đoạn phát triển ban đầu. npm chưa được xác nhận là đã phát hành.

Chạy từ mã nguồn

Clone repository để cài đặt, kiểm thử và build thư viện.

git clone https://github.com/Velclaw/OCode.js.git
cd OCode.js && npm install && npm test

Khi gói được phát hành chính thức, hướng dẫn cài đặt qua npm sẽ được cập nhật.

Xây dựng rõ ràng. Phát triển linh hoạt.
